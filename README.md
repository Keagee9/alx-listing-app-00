# ALX Listing App

## 🏠 Overview
This project is a simplified Airbnb clone built using Next.js. It focuses on building a responsive and scalable property listing interface.

## 📦 Project Structure
- `pages/`: Entry point for the app
- `components/common/`: Reusable components like Card and Button
- `interfaces/`: TypeScript interfaces for component props
- `constants/`: Static configuration and constants
- `public/assets/`: Static images and SVGs

## 🚀 Setup
```bash
npm install
npm run dev
